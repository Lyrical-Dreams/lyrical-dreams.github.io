Operational watch items

Not broken — just easy to forget under pressure.

Network
Home public IP is dynamic. Both WireGuard configs hard-code the home's public IP as the endpoint — check for an ISP reassignment first if remote access ever stops working after an outage.
Certificates
Re-check HTTPS trust after any full restart. The self-signed root cert has needed re-installing on the phone before after a full reboot.
Access scope
WireGuard gets you into Jellyfin, not the tunnel box itself. Administering that container always means being on home WiFi first.
Autostart
Guest autostart has failed silently once before. Worth a glance at the Proxmox UI after any host restart rather than assuming both guests came back up.

Input-Capture Detection Lab

security research

C++ · Windows API · Winsock2

A self-directed research project studying how endpoint monitoring tools detect keylogging behavior, built and run entirely in an isolated virtual lab I controlled end to end.

  • Built a keystroke-capture tool in C++ using low-level Windows API hooks, to understand exactly what signals this class of software leaves behind on a system.
  • Ran the tool exclusively in a sandboxed VM with no network access, generating over 200 hours of controlled test data across a range of input types.
  • Focused the analysis on detection: mapped which behaviors triggered antivirus and EDR alerts, and documented indicators of compromise that defenders could use to flag similar tools.
  • Wrote up findings as a lab report connecting the technical behavior to practical detection guidance, rather than evasion.

Research context only. Built and tested in an isolated environment, never deployed outside the lab.
